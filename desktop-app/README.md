# The Box Lite 0.2

מקום אחד לשיחות עם כלי ה-AI שכבר מותקנים במחשב. ממשק עברי, שיחות מקומיות, בחירת כלי ושמירת ההגדרות. גרסת הקוד הזו מיועדת ל-Windows, ל-macOS ול-Linux; נבנו מתקיני בדיקה בכל ששת היעדים. הם עדיין אינם חתומים, והתקנה ידנית בכל מערכת טרם אומתה.

## שימוש

- מרחב אישי נוצר בפתיחה הראשונה. אפשר להתחיל שיחה בלי לבחור תיקיית פרויקט.
- אפשר לבחור Claude, Codex, Gemini, Grok, Ollama או DeepSeek. התקנה מזוהה אינה הוכחה שהחשבון מחובר; ההתחברות נבדקת בבקשה בפועל.
- חיבור החשבון מתבצע בכלי הרשמי ונשמר על ידו. The Box אינו מעתיק סיסמאות או טוקני התחברות למסד השיחות שלו.
- כלי, פרויקט, שיחה פעילה ומצב חסכוני נשמרים. גם במהלך תשובה אפשר לכתוב את הטיוטה הבאה.
- Lite הוא מצב שיחה ללא שינוי קבצים. סביבת העבודה המתקדמת הקיימת נגישה דרך ההגדרות; היא עדיין דורשת את בדיקות התאימות שלה.
- Ollama בוחר את המודל המקומי הקטן שכבר מותקן, ומדלג על מודלי ענן; לא מתחילה הורדת מודל אוטומטית. במחשב חלש אפשר לבחור כלי ענן במקום להפעיל מודל מקומי.
- DeepSeek דורש מפתח API ויתרה. המתווך קורא את משתנה הסביבה `DEEPSEEK_API_KEY`, או מפתח מילולי שכבר נשמר בקובץ הסודות המקומי של AI Terminals. הוא אינו מריץ את קובץ הסודות ואינו כולל מפתח בקוד ההפצה. אפשר להגדיר `AI_TERMINALS_ROOT` אם תיקיית AI Terminals נמצאת במקום אחר.

## מה קל יותר

- הממשק הראשי נטען משלושה קבצים קטנים, ללא framework וללא פונטים חיצוניים. קטלוג הפקודות הישן אינו נטען במסך הראשי.
- מסלול השיחה משתמש במתווך Rust של האפליקציה עצמה. אין שרת Node קבוע או מתווך PowerShell לכל בקשה. כלים מסוימים, כגון Gemini CLI, עשויים לדרוש Node כחלק מההתקנה שלהם.
- מצב חסכוני מעביר עד ארבעה תורים קודמים שהושלמו, בתקציב של 6,000 תווים. מצב מורחב מעביר עד שמונה, עד 12,000 תווים. הודעות ישנות נשארות בהיסטוריה המקומית.
- ההיסטוריה נטענת בחלקים של 30 תורים עם אינדקסים במסד הנתונים. יצירת תור חדש אינה טוענת את כל השיחה לזיכרון.
- טקסט התשובה מוזרם למסך ונשמר פעם אחת בסיום הבקשה, גם כשנשאר טקסט חלקי אחרי עצירה. סגירה פתאומית של האפליקציה במהלך תשובה עלולה לאבד את החלק שטרם נשמר.
- הגדרות נשמרות בטרנזקציה אחת. בניית release מוגדרת להקטנת הקובץ, ללא סמלי ניפוי.
- [Tauri משתמש ב-WebView של מערכת ההפעלה](https://v2.tauri.app/reference/webview-versions/); האפליקציה אינה אורזת עותק מלא של Chromium.

## בנייה מקומית

נדרשים [תנאי הפיתוח של Tauri למערכת המתאימה](https://v2.tauri.app/start/prerequisites/), Node לצורכי הבנייה ו-Rust.

```sh
cd desktop-app
npm ci
npm run test:ui
cargo test --manifest-path src-tauri/Cargo.toml --lib
npm run tauri -- dev
```

לבניית מתקין:

```sh
# Windows
npm run tauri -- build --bundles nsis
# macOS
npm run tauri -- build --bundles app,dmg
# Linux x64
npm run tauri -- build --bundles deb,appimage
```

כלי שחסר פותח עזרה רשמית להתקנה ומזוהה מחדש כשחוזרים לאפליקציה. הכלים החיצוניים אינם מצורפים למתקין. יש להתקין אותם לפי דרישות הספק, ואז להתחבר פעם אחת. ב-Linux נדרש WebKitGTK מתאים; ב-Windows נדרש WebView2. מחשבי 32 ביט, מערכות הפעלה ישנות ו-ChromeOS אינם יעדי בדיקה בגרסה הזו.

## מטריצת הפצה שהוכנה

הקובץ `.github/workflows/desktop-lite.yml` מגדיר בנייה ידנית (`workflow_dispatch`) ובנייה אוטומטית בענפי `test/the-box-lite-*`. [הריצה הראשונה](https://github.com/DavidPatlas-AI/ai-terminals/actions/runs/42037586780) הסתיימה בהצלחה בכל ששת היעדים. `main` לא שונה ולא פורסם release.

| יעד | סביבת בנייה | חבילה מתוכננת |
|---|---|---|
| Windows x64 | windows-latest | NSIS |
| Windows ARM64 | windows-11-arm | NSIS |
| macOS Intel | macos-15-intel | app / DMG |
| macOS Apple Silicon | macos-latest | app / DMG |
| Linux x64 | Ubuntu 22.04 | DEB / AppImage |
| Linux ARM64 | Ubuntu 22.04 ARM | DEB |

הזרימה מריצה את בדיקות הממשק ואת בדיקות Rust לפני האריזה. התוצרים מוגדרים כלא חתומים; לא מתבצע פרסום release אוטומטי. להפצה למשתמשים יש להשלים חתימה ואימות בכל יעד, וכן notarization ב-macOS לפי מסלול ההפצה שנבחר. [תיעוד Tauri לבנייה ב-GitHub](https://v2.tauri.app/distribute/pipelines/github/).

## מצב האימות במחשב הפיתוח — 5 בנובמבר 2026

- חמש בדיקות יחידה של המתווך Native עברו: הגבלת כלי שיחה, פענוח נתוני curl, ניקוז stderr מוגבל בזיכרון וזיהוי שמות פקודות בטוחים ובחירת מודל Ollama מקומי בלבד.
- בדיקות ההתנהגות של הממשק עברו עם נתוני camelCase התואמים לחוזה Rust: שחזור שיחות והעדפות, אירועים מוקדמים, שגיאות/ניסיון חוזר, טיוטה בזמן תשובה, תצוגת קוד ומניעת הפעלת HTML שהגיע מהמשתמש או מהמודל. אלה בדיקות DOM ולא בדיקת WebView חזותית.
- מנגנון Rust החדש החזיר תשובות חיות מ-Claude, Codex, Gemini, Grok ו-Ollama באמצעות דרייבר אינטגרציה נפרד. DeepSeek החזיר HTTP 402.
- סכמת SQLite והאינדקסים נטענו בהצלחה, ונבדק ששאילתת ההיסטוריה המוגבלת משתמשת באינדקס המתאים.
- בדיקת הטיפוסים של מודולי Native עברה. בניית האפליקציה המלאה נחסמה בקובץ עזר של הבנייה על ידי Windows Application Control, שגיאה 4551. בדיקת מקור מלאה נוספת נעצרה גם עקב מטמון תלות Tauri לא תקין (`E0463`). קומפילציה מלאה של 0.2 ובדיקות הקוד הושלמו בהצלחה בענן בכל ששת היעדים. ב-Windows x64 עברו 85 בדיקות Rust, עם 6 בדיקות חיות שהושארו מחוץ לריצה.
- ניסיונות הפעלת דפדפן אוטומטי לצורך צילום נכשלו בסביבה. התצוגה המצורפת מיועדת לבדיקה חזותית ידנית, והיא מסומנת בבירור כתצוגה מקדימה ללא חיבור לשירותים.
- נבנו מתקיני macOS/Linux/ARM בענן; בדיקת התקנה ידנית על כל מערכת טרם הושלמה. אין לייחס ל-0.2 את קובץ ה-EXE הישן מ-0.1.
- לא שונו הגנות Windows. החתימה ובדיקת ההפעלה המלאה נשארו פתוחות.

## קבצים מרכזיים

- `desktop-app/src/lite.html`, `lite.css`, `lite.js` — הממשק החדש.
- `desktop-app/src-tauri/src/worker.rs` — חיבורי השיחה Native.
- `desktop-app/src-tauri/src/platform.rs` — גילוי פקודות ופעולות לפי מערכת ההפעלה.
- `desktop-app/src-tauri/src/adapters/connected.rs` — הקשר שיחה, אירועים ושמירה.
- `desktop-app/src-tauri/src/db/indexes.sql` — אינדקסים להיסטוריה.
- `desktop-app/tests/lite.test.cjs` — בדיקות הממשק ללא חשבונות אמיתיים.

חבילת המקור אינה כוללת `.env`, מפתחות API, שיחות, מטמונים, `node_modules` או קובצי הפעלה ישנים.
